Log ind som redaktør

Når du er logget ind, kan du klikke på teksterne på siden og rette dem. Tryk Gem ændringer nederst – så er siden opdateret på nettet efter ca. 1 minut.

Sådan laver du en adgangsnøgle (kun for administrator)
  1. Gå til GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Repository access: Only select repositories → lokale-beredskabsplaner.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Vælg udløbsdato (fx 1 år), opret og giv nøglen til redaktøren.
